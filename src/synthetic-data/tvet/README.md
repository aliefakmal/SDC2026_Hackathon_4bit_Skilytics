# Synthetic TVET outcomes

Fictional aggregate outcomes for 2024–2026, for dashboard and AI demonstrations only. The same reference template is clearly labelled when shown in any institution portal. It is not that institution’s measured graduate employment. Each row has mutually exclusive outcomes summing to graduates. Employment excludes further study. No personal records.

Source of truth: `graduate-employment-2024-2026.json`. Identical distribution copy at root `synthetic data/`. Do not mix this fixture with real student progress. Scenario: +2 percentage points per year from 2026, capped at 100%, explicitly hypothetical.
